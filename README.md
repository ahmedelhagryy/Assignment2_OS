sudo apt install gcc

 Read Documentation
Before running the programs, check:
Screenshots.pdf
 This file explains what each program does.

 Using the Makefile
You can run all programs easily with make:
make            # Build and run all tasks
make task1      # Run Task 1
make task2      # Run Task 2
make task3      # Run Task 3
make clean      # Remove generated output files

 Running Programs Manually with GCC

You may also compile each file manually:

gcc p.c -o out


Replace Task-1.c with the file you want to run.
The output executable will be named out
